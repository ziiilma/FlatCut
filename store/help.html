FlatCut

DXF and SVG for laser cutting from Fusion in one click. Windows and macOS.

Where to find it

Design workspace → Utilities tab → Add-Ins panel → Export to Laser.

What it does

  • Finds every flat plate and sheet metal part in the design and counts identical parts.
  • Creates the flat pattern for bent sheet metal by itself, including rolled shells (cylinders, cones). This is the only change made to your design, and it happens only when you press Export. A broken flat pattern is deleted and recreated only after you confirm.
  • Writes one DXF R2000 per part: closed contours, arcs instead of splines — reads in LightBurn, CypCut, SigmaNEST, Lantek, RDWorks. In CypCut engraving and bend lines land on layer 2, cut lines on the default layer.
  • Layers: CUT, ENGRAVE (pockets up to 1 mm deep and the part number as single-line text), BEND_UP / BEND_DOWN.
  • Files with anything to engrave get the Gr_ prefix (Гр_ in the Russian interface).
  • Optional SVG for Glowforge, xTool, LightBurn.
  • preview.pdf on A3 (mm) or Tabloid 11×17 (inches) sheets: every part with overall size and dimensions to bend lines.
  • Pre-cut check after export: holes smaller than thickness, thin webs, tiny contours, text that does not fit.

Dialog

Assemblies in orderMultiplies all quantities.

File name, field 1–4Thickness, quantity, part name, part number, material — in any order (default: thickness, quantity, part name, part number). An example is shown below.
Bend linesAdds BEND_UP / BEND_DOWN layers.
Engrave part numberPart number as single-line text on the ENGRAVE layer; set the text height. Only the distinguishing end is engraved: the start shared by all exported parts is dropped (ABC.91.02.00.005 → 02.00.005). Works online only: Fusion does not give part numbers offline.

The preview uses the bundled Liberation Sans font (SIL Open Font License, resources/fonts).

Settings are remembered in ~/.flatcut.json. The interface follows the Fusion language (English or Russian).

Notes

  • Exit Flat Pattern mode before running.
  • Flat bodies and Sheet Metal bodies are exported. A bent plate modelled as an ordinary body is listed greyed — convert it to Sheet Metal. Tubes and rolled profiles are not listed.
  • If Fusion makes a non-flat flat pattern, the part is listed as skipped — delete the flat pattern in the browser and run again.
  • Exporting again into the same folder replaces the old files.
